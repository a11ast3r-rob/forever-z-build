# Forever Z Build

A living build journal for my planned Nissan 370Z — starting before the car is even in the driveway.

## Current direction

- Current candidate: 2009 Nissan 370Z Base — Pearl White, black interior, 6-speed manual, 112,563 miles
- RAYS Gram Lights 57DR in Gunblue
- Street/highway-friendly tire fitment
- Air suspension with real drive-height alignment
- Two smaller hidden air reservoirs + dual electric compressors
- Custom audio / subwoofer installation
- Sound treatment
- Possible thermostatic oil cooler
- Battery-first home garage tool collection
- Forever-car mentality: usable, serviceable, personal

## Site

The GitHub Pages homepage is now an **interactive Mission Control** in `index.html`: acquisition checklist, longevity plan, tool links, build modules, local browser progress, budget fields, research links, and a scratchpad.

## How we'll maintain it

Every meaningful change should do two things:

1. Update the relevant current-plan document/site section.
2. Add a dated note to `BUILD_LOG.md`.

That way the website shows the current plan while the build log and Git history preserve how the car evolved.
